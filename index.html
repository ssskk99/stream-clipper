Stream Clipper

A personal tool that turns Twitch stream highlights into vertical short videos and uploads them to its owner's YouTube channel.

Stream Clipper runs on its owner's own Windows PC. When a followed Twitch stream ends, it finds the most interesting moments, cuts them into 1–3 minute vertical clips with captions, and writes a title and description for each one. The owner reviews the clips and, if they choose, uploads them to their own YouTube channel as Shorts. Each upload credits the original streamer and links to the source stream.

Stream Clipper is not a public service. It has no user accounts and no website other than this page, and it is used only by the owner of the YouTube channel it posts to.

Privacy policy

Last updated: November 18, 2026

Google user data it accesses

Stream Clipper asks for one Google permission: upload videos to your YouTube channel (https://www.googleapis.com/auth/youtube.upload). It uses this permission only to upload clips the channel owner has made with the tool, together with each clip's title and description. It does not read, change or delete your existing videos, comments, subscriptions, playlists, or any other account data.

How it is stored

The sign-in token Google issues is saved only in a file on the owner's own computer. It is never sent anywhere except to Google when uploading. Stream Clipper has no servers and collects no analytics.

Sharing

Stream Clipper does not sell, share or transfer Google user data to anyone. To pick highlights, it sends text transcripts and chat activity from public Twitch streams to Anthropic's Claude API. This is public stream content, not Google user data.

Limited Use

Stream Clipper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service; see also the Google Privacy Policy.

Removing access

You can revoke Stream Clipper's access at any time at myaccount.google.com/permissions. Deleting the token file from the computer also removes it permanently.

Changes and contact

If this policy changes, the date above will be updated. For questions, open an issue on the GitHub repository that hosts this page.
